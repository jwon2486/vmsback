경비실 경보음 폴더
==================

여기에 음원 파일을 넣으면 경비실 화면이 그 소리로 울립니다.
서버 코드는 고치지 않아도 됩니다. 파일만 바꾸면 됩니다.

파일명 (js/sec-alarm.js 의 ALARM_SOURCES 와 일치해야 함)
  sec-alert.mp3    ← 기본. 이 이름으로 넣어 주세요.
  sec-alert.wav    ← mp3 가 없으면 이 파일을 찾습니다.

없으면 어떻게 되나
  브라우저가 코드로 만든 경보음(삐-삐-)으로 자동 대체됩니다.
  소리는 나지만 밋밋하므로, 실제 운영에는 음원 파일을 권장합니다.

음원 고를 때
  - 1~2초 길이. 길면 반복 간격과 겹칩니다.
  - 시작하자마자 소리가 나야 합니다(앞부분 묵음 금지).
  - 경비실이 시끄러우면 고음 위주가 잘 들립니다.
